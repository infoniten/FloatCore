# Резервные копии конфигурации VESC

Снимки состояния ESC, сделанные через CAN средствами FloatCore. Лежат в
репозитории намеренно: копия, существующая только на одном ноутбуке, — не
копия.

## Что где

| Каталог | Момент | Что внутри |
|---|---|---|
| `v0.7d1/` | до самых первых изменений конфигурации | обе половины, mcconf + appconf + fw |
| `v0.8a-pre-motor/` | начало этапа подключения мотора | обе половины |
| `v0.8a-pre-detection/` | после пределов прокрута, **до** детекции FOC | только 118 |
| `v0.8a-post-detection/` | после детекции — **текущее состояние** | только 118 |

Половина 100 за весь этап v0.8A не менялась, поэтому её последний снимок
лежит в `v0.8a-pre-motor/` и остаётся актуальным.

## Какой снимок для чего

**`v0.7d1/`** — «как было до нас». Сюда откатываться, если понадобится вернуть
машину в исходное состояние целиком.

**`v0.8a-pre-detection/`** — точка возврата, если результаты детекции окажутся
неверными. Содержит верное число полюсов и пределы прокрута, но ещё старые
R, L и λ.

**`v0.8a-post-detection/`** — то, что в железе сейчас. С ним сравнивать, чтобы
заметить постороннее изменение.

## Формат

`.bin` — ответ `COMM_GET_*` целиком, **включая первый байт с номером пакета**.
Сериализованная конфигурация начинается со второго байта, и первые её четыре
байта — сигнатура раскладки (`2efd0142` у mcconf, `7d217eb8` у appconf).

`.json` — те же байты в hex плюс разобранные поля, сигнатура и отметка.

## Сравнить текущее состояние с копией

```
python3 tools/esp32_console.py --pre can-diag-reset --window 2 \
    --post "can-diag-hex mcconf 118" --out /tmp/now.log
python3 tools/vesc_diff.py --before backups/vesc/v0.8a-post-detection/mcconf_id118.bin \
    --after-log /tmp/now.log --request GET_MCCONF --id 118
```

Расхождения в `foc_offsets_current[0..2]` и `foc_offsets_voltage[0..2]`
ожидаемы: ESC перемеряет их при каждом включении. Всё остальное означает, что
конфигурацию кто-то менял.

## Откат

Процедура — `docs/esc_config_checkpoint.md` §2. Коротко: питание снять, мотор
отключить, восстановить через VESC Tool по USB, перечитать через CAN и
сверить побайтово.
