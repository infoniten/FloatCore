# Модель батареи и напряжений

Документ этапа v0.7D. Батарея — **10S Li-ion**, подтверждено владельцем.
Значение в конфигурации FloatCore приведено к 10; изменения в конфигурации
ESC подготовлены, но **не применены**.

Проверки в исполняемом виде: `compat/safety/fc_battery_model.{h,c}`,
тесты — `tests/safety/test_motor_prep.c`.

---

## 1. Три числа ячеек, два из которых были неверны

| Где | Было | Стало | Кто это читает |
|---|---|---|---|
| Прошивка ESC, `si_battery_cells` | **3** | 3 (изменение подготовлено) | только оценка остатка заряда самим ESC |
| FloatCore, `floatcore_limits.c` | 20 | **10** | путь host и протокол |
| FloatCore, `fc_vesc_if.c` | **15** | **10** | **Refloat на плате** |

Числа не дублируют друг друга, и путать их нельзя: Refloat работает на ESP32
против нашего `VESC_IF`, поэтому он видит **наше** число, а не то, что стоит
в ESC. Именно наше и было самым вредным.

После правки оба места FloatCore берут значение из одного источника —
`fc_battery_cell_count()`, а он защищён от нуля: `FC_BATTERY_CELLS_DEFAULT`.
Ноль здесь особенно коварен, потому что Refloat умножает пороги на число
ячеек **только если оно больше нуля** (`motor_data.c:80`), иначе трактует
«3.0 В» как абсолютный порог для всей батареи, и откат не срабатывает никогда.

## 2. Кто чем управляет

**Защиты прошивки ESC числом ячеек не пользуются вовсе.** Они работают в
абсолютных вольтах (`mc_interface.c:2440-2458`). Неверное `si_battery_cells`
их не ослабляет — это единственная причина, по которой ошибка прожила так
долго незамеченной.

**`si_battery_cells` в прошивке ESC** используется в одном месте: оценке
остатка заряда `mc_interface_get_battery_level()` (`mc_interface.c:1560-1580`).

**У Refloat он влияет на безопасность:**

```c
// refloat-upstream/src/motor_data.c:79-88
uint8_t battery_cells = VESC_IF->get_cfg_int(CFG_PARAM_si_battery_cells);
if (battery_cells > 0) {
    if (lv_threshold < 10) lv_threshold *= battery_cells;
    if (hv_threshold < 10) hv_threshold *= battery_cells;
}
```

## 4. Политика низкого напряжения

**Задача:** предупредить водителя **до** того, как пропадёт тяга.

ESC начинает срезать входной ток на 34.0 В и обнуляет его на 31.0 В. Значит
порог отката Refloat обязан быть **выше 34.0 В** — это прямо написано и в
описании самого параметра `tiltback_lv` в `settings.xml`:

> Make sure your Voltage Cutoff Start and End are below this threshold!

Значение Refloat по умолчанию — 3.0 В/ячейку, то есть 30.0 В. **Это ниже
34.0 В**, и с ним водитель узнавал бы о разряде по исчезнувшей тяге.

### Сколько запаса нужно

Порог нельзя ставить впритык к 34.0 В: под нагрузкой напряжение проседает, и
оба механизма смотрят на одно и то же фильтрованное напряжение. При входном
токе 15 А и внутреннем сопротивлении 10S-сборки порядка 50 мОм просадка
составляет около 0.75 В. Округляем до **1 В**.

```
tiltback_lv = 34.0 + 1.0 = 35.0 В = 3.5 В/ячейку
```

**Предлагается 3.5 В/ячейку.** Значение не унаследовано из v0.7C, а выведено:
это отсечка ESC плюс запас на просадку. Проверяется тестом
«предлагаемая политика 3.5/4.1 В/яч сходится».

Цена: предупреждение приходит примерно на 20-25 % остатка заряда. Для
самобалансирующейся доски это правильная сторона ошибки — тяга нужна не для
скорости, а для того, чтобы стоять.

## 5. Политика высокого напряжения — зеркальная задача, и она хуже

Значение Refloat по умолчанию `tiltback_hv = 4.3 В/ячейку` даёт **43.0 В**.

Для 10S Li-ion **полностью заряженная батарея — это 42.0 В**. Порог 43.0 В
физически недостижим: предупреждение о высоком напряжении **не сработает
никогда**.

При этом ESC начинает срезать regen уже на 41.5 В и обнуляет его на 42.0 В.
То есть на полной батарее тормозная способность пропадает молча.

Для доски это опаснее, чем низкое напряжение: рекуперативное торможение —
это и есть способность остановиться. Потерять её без предупреждения, съезжая
с горки на свежезаряженной батарее, — известный сценарий падения.

```
tiltback_hv = 4.1 В/ячейку = 41.0 В  (на 0.5 В раньше начала regen-отсечки)
```

**Предлагается 4.1 В/ячейку.** Следствие, которое надо принять осознанно: на
полностью заряженной батарее (42.0 В) доска будет давать откат сразу, пока
напряжение не опустится ниже 41 В. Это не дефект, а честный сигнал —
рекуперативное торможение в этот момент действительно недоступно.

Поднять вместо этого regen-отсечку нельзя: 4.2 В/ячейку — предел химии.
Двигать надо порог предупреждения, а не защиту.

### Дополнительный слой, о котором легко забыть

`l_in_current_min = 0.0` означает, что **входной ток в батарею запрещён
полностью** — рекуперация не заряжает батарею вообще. Тормозная способность
при этом ограничена тем, что ESC может рассеять, и не зависит от заряда.

Это надо либо подтвердить как осознанное решение, либо исправить вместе с
пределами тока. Сейчас оно работает в безопасную сторону и заодно частично
снимает остроту вопроса regen на полной батарее.

## 6. Лабораторный источник и первый прокрут

**30 В лабораторника — это стенд для софта и CAN, и ничего больше.**

```
v_in измерено через CAN: 30.3 В (ID 118), 30.1 В (ID 100)
l_battery_cut_end = 31.0 В
```

При таком напряжении ESC держит входной ток **ровно нулём**
(`mc_interface.c:2442`: `v_in < cut_end + 0.1` → `lo_in_max_batt = 0`).
Попытка получить вращение на 30 В даст ложный отрицательный результат: мотор
не крутится не потому, что что-то сломано, а потому что ток запрещён.

**Отсечки под лабораторник НЕ снижаются.** Это защита батареи, а не помеха
тесту. Снизить 34/31 В ради удобства стенда означало бы отключить защиту
ровно в тот момент, когда впервые появится реальный ток.

### Первый физический прокрут — от реальной 10S батареи

* Проверить напряжение мультиметром до подключения.
* **Не брать батарею на абсолютных 42.0 В.** При полном заряде regen срезан,
  а предлагаемый порог отката 41.0 В сработает сразу. Разумный диапазон для
  первого теста — примерно 37-40 В, то есть около 3.7-4.0 В на ячейку.
* Колесо вывешено, доска закреплена, человек на доске не стоит, зона
  вращения свободна.

## 7. Что остаётся несогласованным

| Что | Состояние |
|---|---|
| FloatCore, число ячеек | **исправлено на 10** |
| ESC, `si_battery_cells = 3` | изменение подготовлено, не применено |
| Refloat `tiltback_lv = 3.0 В/яч` | изменение подготовлено (3.5), не применено |
| Refloat `tiltback_hv = 4.3 В/яч` | изменение подготовлено (4.1), не применено |
| `l_in_current_min = 0.0` | требует осознанного решения |

Пока пороги Refloat не изменены, **модель остаётся противоречивой**, и это
блокирует моторный этап: `fc_battery_model_valid()` на текущих значениях
возвращает false, а соответствующий вход контракта разрешения
(`battery_model_valid`) остаётся ложным.
