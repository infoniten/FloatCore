# Первый короткий прогон замкнутого контура Refloat (ТЗ v0.9K)

Впервые выполнен непрерывный замкнутый контур

```
IMU -> Refloat 500 Гц -> Motor Gate -> координатор -> CAN -> обе половины VESC
```

на закреплённом стенде с вывешенным колесом. Пять прогонов: 100, 100, 150,
250, 500 мс, каждый — после чекпойнта и отдельного подтверждения оператора,
после каждого — остановка и разбор. Человека на стенде не было, рама
закреплена, колесо в воздухе.

Это НЕ езда и НЕ свободная доска. Балансировка по этим прогонам не
оценивается: рама закреплена, и угол меняться не может (§12, §14).

## B. Сборка и состояние

```
сборка контура  build_cl: -DFLOATCORE_PROFILE=experimental -DFLOATCORE_CLOSED_LOOP=1
                (FLOATCORE_REFLOAT_REAL_MOTOR_LOOP; без experimental не собирается)
после серии     LAB_SAFE, smoke PASS: backend отсутствует, DISARMED, physically_sent 0
EXP             загружается DISARMED, само не вооружается
символы         LAB_SAFE: мотора нет; EXP: транспорт есть, контура нет;
                build_cl: и то и другое
```

Состояния прогона (§6):

```
DISARMED -> ready -> READY -> motor-arm -> cl-ready -> ARMED («готов к
контуру», тяги нет) -> cl-burst <мс> -> RUNNING со сроком -> сам -> DISARMED
```

Срок держат два независимых пути (§7):

* **гейт** проверяет срок на КАЖДОМ запросе; после срока отзывает прогон сам и
  снимает бит REFLOAT. Новый прогон — только новым вооружением;
* **супервизор** сам выходит из RUNNING в DISARMED при опросе (100 Гц).

После прогона платформа снимает всё: гейт, имитацию датчиков, координатор,
супервизор. Повторного вооружения нет.

### Датчики ног (решение оператора)

Refloat подаёт ток только при нажатых датчиках ног; на стенде нажатие —
имитация. Правило: READY — только на свободной доске; в ARMED и RUNNING нажатие
допустимо ТОЛЬКО с признаком имитации (новый вход супервизора
`footpad_simulated`). Настоящее нажатие снимает ARMED/RUNNING сразу, без
ожидания опроса.

Найден и исправлен давний пробел: супервизор узнавал о датчиках ног ОДИН раз, при
загрузке. Теперь их состояние сообщается каждый период супервизора.

## J. Реальное время

### Первый прогон: NO-GO по пропускам

`refloat_thd` missed +19 (max период 5843 мкс). Контур, датчик и супервизор —
0. Запросы тока шли ровно (max интервал 2405 мкс).

### Причина — разбор без тяги

Передача пары вызывается из `imu_ref_callback`, то есть в задаче `fc_imu_rt`
(ядро 1, приоритет 14), выше `Refloat Main` (ядро 1, 12). Путь стоил 408 мкс в
среднем — около 20 % периода при запасе ядра 1 около 19 %.

Две гипотезы отвергнуты измерением: копирование структур CAN (сбор входов
целиком 19 мкс) и блокировка передачи (очередь TX на 4 кадра).

Подтверждена третья: тот же код в контуре выполняется в разы медленнее, чем в
пробе на том же ядре, — промахи кэша инструкций, как у драйвера I²C в v0.9I.

| на ядре 1 | проба | контур, flash | контур, IRAM |
|---|---|---|---|
| сбор входов + план координатора | 24 мкс | 142–185 | **23** |
| отвергнутый запрос в гейт | 1–2 | 14–22 (до 46) | **2–3** |
| `twai_transmit` | 34–40 | — | **7** |

Лечение: `platform/esp32/main/cl_iram.lf` — код гейта, супервизора,
координатора, транспорта, журнала и драйвера TWAI в IRAM (только текст;
DRAM свободно ~8 КБ и не тронута). Только в сборке контура. IRAM +20.6 КБ,
свободно 39.5 КБ.

Квалификация без тяги: 3 мин Refloat в RUNNING, все запросы отвергаются —
missed 0, late 0 во всех каналах, зазоров IMU 0; простой ядра 1 в RUNNING
21.3 % (v0.9I: 19.2 %).

## P. Вердикт

**GO — только для следующего, более длинного прогона на ЗАКРЕПЛЁННОМ стенде**
(отдельным ТЗ: v0.9K ограничен 500 мс, и потолок достигнут).

НЕ GO для человека. НЕ GO для свободной доски. Коэффициенты не менялись.

Открыто:

1. ERPM после снятия тока растёт ещё ~50–100 мс (500 мс: −1800 при снятии,
   −2071 через 120 мс). Без момента колесо разгоняться не может — вероятно,
   запаздывание оценки скорости VESC. Решения по ERPM не принимались; разобрать
   до того, как на ERPM что-либо опирать.
2. Реакция рамы: угол растёт на ~0.06° за 500 мс под моментом. Для стенда —
   свойство крепления, не контура.
3. Батарея в этой серии мультиметром не проверялась.
4. Отказные впрыски во время прогона (§20: IMU HOLD, узел молчит) не
   выполнялись — только отдельным чекпойнтом.
